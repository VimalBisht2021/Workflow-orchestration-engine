# Release Checklist

While the Definition of Done (DoD) applies to individual feature PRs, this Release Checklist applies to shipping an actual release to production environments.

- [ ] Release notes written
- [ ] Version bumped (SemVer)
- [ ] Changelog updated
- [ ] Migration verified (e.g., database schemas)
- [ ] Rollback plan documented
- [ ] Smoke tests pass in staging environment
- [ ] Docker Images signed and published to registry
- [ ] Dependency updates applied and verified
